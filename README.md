# Aiden and His Hungry Friend

A children's picture book about Aiden, an energetic boy visiting Hawaii, and Trevor, his young chimpanzee friend. Their adventures explore eating, chewing, resting, and cooking through play and conversations with Aiden's family.

This repository holds illustration work and concise project documentation.

## Source of truth

The user maintains the [live storyboard, illustration directions, and approved-page notes](https://docs.google.com/document/d/1f6nbea5M4BJEsfQdq17SvxFLUpuSjPrzEQhwimhki0I/edit?tab=t.0) in Google Docs. **That document is ground truth** and can change independently of this repository. Check the relevant section before working; repository notes are navigation aids, not a replacement manuscript.
