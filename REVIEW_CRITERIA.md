# Page 3 and 4 review criteria

Scope: opening sequence, source-listed Aiden_page_03.png and explicit Page 4 heading. Recheck the live storyboard before future changes. Reference paths and exact manuscript excerpts are in [reference provenance](assets/references/README.md).

## Required checks

1. **Source fidelity:** Every word and punctuation mark matches the relevant current manuscript. Read the actual image; model self-assessment alone does not pass this check. Decorative example text is not manuscript authority.
2. **Layout:** Complete spread has equal left text/right character sections. Text stays within ivory botanical page, with legible margins; no text overlaps the right illustration. Separate exports preserve the entire corresponding half.
3. **Character continuity:** Compare actual output side by side with the approved page 2/page 3 references. Preserve Aiden's curly brown hair, freckles, yellow shirt and blue shorts, and Trevor's young chimp proportions, dark fur and peach face. Trevor has no tail.
4. **Story action:** Page 3 preserves the approved Trevor-eating scene. Page 4 clearly shows Aiden rubbing tired cheeks while Trevor continues eating. Hands and limbs must be coherent and gestures readable.
5. **Visual quality:** Consistent warm watercolor/gouache treatment, expressive friendly faces, dappled light, layered foliage, restrained outlines and clean composition. No accidental image-frame UI, unwanted letters, watermarks, missing limbs or distracting artifacts.
6. **Asset integrity:** Open the saved files, record dimensions and SHA-256 hashes, and verify separate exports against the selected spread. Preserve original downloads and versioned revisions; never overwrite approved source references.
7. **Handoff:** Register the selected asset paths, exact prompt/revision prompts, model evidence, conversation URL, observed defects and resolved changes, review date and next action. Distinguish agent review passed from user approval and print-production readiness.

## Revision loop

The orchestrator inspects the actual candidate, gives the page agent a specific correction prompt naming visible defects, and rechecks the saved revision. Repeat while fixable defects remain. Stop only at verified review pass or a concrete external blocker; record that blocker without checking the completion box. Do not substitute a model for the requested browser 6 Pro without user direction.

For source-approved page 3, preserve pixels and wording rather than repainting to match newer general style guidance. Browser packaging should be lossless. For new page 4, use the current text-page and character style references together with approved character identity. User approval of page 4 remains a separate decision.
